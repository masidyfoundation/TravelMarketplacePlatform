# Masidy Production Roadmap

This checklist is implemented in dependency order. External credentials, provider
accounts, domains, callback URLs, legal text, and business policy values remain
deployment configuration rather than hard-coded application data.

## Foundation

- [x] Responsive marketplace for mobile, tablet, and desktop
- [x] Payload-managed agencies, trips, media, bookings, users, and orders
- [x] Traveler, agent, agency, and guest workspaces
- [x] Google and passwordless email authentication wiring
- [x] Stripe Checkout and webhook wiring
- [x] Role-aware Masidy Make AI workspace
- [x] Automatic marketplace cache invalidation and resilient refresh
- [x] Public guest demo across all three roles

## Phase 1 — Product, onboarding, and discovery

- [x] Rich trip content model
- [x] Agency profile extensions
- [x] Dated departure and capacity inventory
- [x] Traveler saved trips
- [x] Verified review workflow
- [x] Agent and agency onboarding applications
- [x] Support case workflow
- [x] Public trip detail pages
- [x] Public agency detail pages
- [x] Signed-in partner application form
- [x] Application status tracking and resubmission
- [x] Agency inventory management UI
- [x] Agent storefront management UI
- [x] Persistent traveler wishlists in the public UI

## Phase 2 — Resale and booking operations

- [x] Public agent storefronts and shareable attribution links
- [x] Proposal and quotation workflow
- [x] Availability locking and reservation expiry
- [x] Amendments, cancellations, waitlists, and vouchers
- [x] Traveler document and emergency-contact management
- [x] Secure traveler-agent-agency messaging
- [x] Notification center and scheduled reminders

## Phase 3 — Finance

- [x] Stripe Connect onboarding for agencies and agents
- [x] Split payments, platform fees, and commission ledger
- [x] Payout schedules and statements
- [x] Refunds, partial refunds, disputes, and commission reversals
- [x] Tax, VAT, invoicing, and multi-currency policy engine
- [x] Reconciliation exports and finance dashboard

## Phase 4 — Masidy Make AI

- [x] Structured, editable page sections
- [x] Visual page preview and publishing
- [x] Brand kits, reusable templates, and version history
- [x] Inventory enrichment and pricing intelligence
- [x] Trip matching and proposal generation
- [x] AI support assistant with workspace context
- [x] AI usage, moderation, and cost controls

## Phase 5 — Trust, scale, and launch

- [x] Transactional email, SMS, or WhatsApp delivery
- [x] Rate limiting, CAPTCHA, fraud detection, and file scanning
- [x] Audit logs, consent, privacy export, and account deletion
- [x] Terms, privacy, cancellation, and marketplace policy content
- [x] End-to-end, webhook, load, accessibility, and security testing
- [x] Monitoring, analytics, alerting, backups, and retry queues
- [x] Localization, currencies, time zones, sitemap, and structured SEO
- [ ] Production domain and provider callback registration
